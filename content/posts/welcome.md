Welcome! I decided it was time to overhaul my personal website with a cleaner, faster theme.

### Why Hugo & PaperMod?

Previously, I had experimented with a few heavier templates, but I wanted something that was:
1. **Blazing Fast:** Compiles in milliseconds, with instant previews locally using `hugo server`.
2. **Minimal & Readable:** PaperMod provides clean typography, distraction-free reading, and native dark/light mode toggle.
3. **Easy GitHub Pages Deployment:** Deploys in seconds with a simple GitHub Actions workflow on every push.
