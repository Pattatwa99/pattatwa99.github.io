This website serves as my digital hub for sharing software projects, writing technical guides, and documenting experiments.

### Highlights
- **Automated Deployment:** Pushing to GitHub triggers GitHub Actions to build and deploy to GitHub Pages automatically.
- **Search & Archives:** Full client-side fuzzy search powered by Fuse.js and date-indexed post archive.
- **Lightweight & Fast:** Zero heavy JavaScript dependencies, scoring 100/100 on PageSpeed.
- **Clean Aesthetic:** Modern PaperMod theme with custom animated profile and light/dark mode.

### Tech Stack
- Hugo Extended
- PaperMod
- GitHub Actions & GitHub Pages
